# Claude entry point

Follow [AGENTS.md](AGENTS.md) for the brain protocol and [SPEC.md](SPEC.md) for the file contract. Start from the manifest, root index, relevant current-state document, current journal context, and whatever is waiting in `inbox/`. Triage inbox items out to their owners; preserve sources as sources; maintain synthesis in wiki; put current state and follow-ups in their owner; append meaningful work to the journal; use strict work only when configured.

Edit Markdown and YAML directly. The optional command, editor, and views automate or present the same contract but are never required at runtime.
