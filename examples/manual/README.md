# Manual examples

These files demonstrate domain recipes without requiring the CLI:

- `software/change.md`: `software` domain plus `work`
- `personal/goal.md`: `personal` domain plus `work`
- `research/finding.md`: `research` domain; no work module required
- `travel/trip.md`: `travel` domain plus `work`

They are individual documents, not complete brains — for a complete one, see [`../nursery/`](../nursery/). Copy the relevant shape into a brain initialized with the matching domain and module, then use paths and links relative to that brain.
